# Security Policy

## Supported Versions

Only the latest release is supported. As updates and security patches are added, new releases will come out and blogs should update accordingly. 

## Reporting a Vulnerability

Vulnerabilities can be reported by opening an issue on this GitHub repository. You may also privately report vulnerabilities if you wish by emailing me at rainier39@proton.me.

I will respond to emails and issues as soon as I can. Depending on the nature of the problem, I will begin working on a solution or inform you if it will not be fixed. If I plan on only addressing the issue sometime beyond the near future, I will try to give some sort of timetable estimate.

Be sure to specify what version of the software you found the vulnerability on, what PHP/MariaDB/MySQL/Apache/Nginx versions you are using, which page/endpoint the vulnerability is present on, and the steps needed/payload to exploit the vulnerability. If you found the vulnerability through source code analysis please specify the file(s) and relevant line number(s). You may also specify what name/alias you wish to be used to credit you for finding the vulnerability, if applicable.

As this is open-source software and a very small project, you are welcome to report issues publicly on the issues page of this repository. If this software gets more popular and ends up in use by some websites, it may become appropriate to report serious vulnerabilities privately.
